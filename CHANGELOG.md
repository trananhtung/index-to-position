# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0]

### Added

- Initial release: `index_to_position`, `index_to_position_with`, and `PositionFinder` — a
  zero-dependency, `no_std` port of the `index-to-position` npm package, using byte offsets,
  with independently configurable one-based line/column.
